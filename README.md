1. Cel projektu

Celem projektu jest stworzenie prostej aplikacji kalkulatora w języku Python oraz przygotowanie testów jednostkowych sprawdzających poprawność działania poszczególnych operacji matematycznych.

2. Funkcjonalności

Klasa Calculator umożliwia wykonywanie podstawowych działań:

dodawanie sum()
odejmowanie subtract()
mnożenie multiply()
dzielenie divide()
obsługę próby dzielenia przez zero

3. Struktura projektu

calculator.py zawiera klasę Calculator
test_calculator.py zawiera testy jednostkowe

4. Testowanie

Do testowania wykorzystano unittest oraz pytest.

Testy sprawdzają:

poprawność dodawania
poprawność odejmowania
poprawność mnożenia
poprawność dzielenia
próbę dzielenia przez zero

5. Pokrycie testami

Do sprawdzenia pokrycia kodu testami wykorzystano bibliotekę coverage.
Dla kodu calculator.py uzyskano 100% pokrycia testami.
